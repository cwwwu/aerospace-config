# aerospace-config

My configuration for [AeroSpace](https://github.com/nikitabobko/AeroSpace), an i3-like tiling window manager for macOS.

## Setup

Clone into AeroSpace's config directory:

```sh
git clone git@github.com:cwwwu/aerospace-config.git ~/.config/aerospace
```

AeroSpace reads `~/.config/aerospace/aerospace.toml`. Note that `~/.aerospace.toml` takes precedence if it exists. Reload with `alt-shift-c` after making changes.
